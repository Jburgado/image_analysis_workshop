# UCSF-CALM Image Analysis workshop 2026

## Goals
Image Analysis methods have gotten a dramatic boost from Artificial Inteligence.  Novel and very powerful segmentation methods have emerged, but it also has become much easier to generate code that will execute multiple image analysis tasks as desired.

This course aims to teach you fundamentals of image processing, so that you will stay in charge of what AI and code will accomplish.  We will use this knowledge and AI to generate code that will execute the image analysis functions.  

We will use the Python coding language.  Python is widely used in science and myriads of libraries exist that facilitate executing complex functions.  These libraries not only are the main power of Python, but also present complexity since it can be difficult to install different libraries and get them all to work in one environment.  Multiple ways to manage environments exist, we will use a modern tool called "uv" for Python environment management.  

The Python code generated by the AI will ensure that your image analysis methods are reproducible and can be inspected by you and others.  You will regularly be making changes to the generated code.  Therefore, proper management of the code, allowing you to go back to a known state and share it with others, is criticial. To this end we will use the source code repository system "git".  Git is a decentralized source code repository, meaning that you will have the complete history of your code on your own computer.  Nevertheless, it is useful to have a backup, and a central place to share your code with others.
